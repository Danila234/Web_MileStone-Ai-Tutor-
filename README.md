# AI Tutor

A step-by-step homework assistant for school students and their parents.

## Team
- Daniil Bratochkin — Team Lead + Backend
- Miras Nusupov — Frontend + UI/UX
- Zhakiyan Bakhtiyaruly — ML-AI + DevOps-QA

## Stack
- Frontend: Vue 3 + Vite
- Backend: Python + FastAPI
- Database: SQLite (dev) / PostgreSQL (prod)
- ML: EasyOCR
- AI: Google Gemini (free tier)
- Payment: YooKassa (Demo Store)

## Project Structure
- `frontend/` — Vue 3 app
- `backend/` — FastAPI server
- `ml/` — OCR scripts and AI prompts
- `docs/` — project documentation
